# Credits

DropBeat was built by Kaushik Siva, beginning as a Kriya add-on and then becoming a standalone native app and local studio.

- **SwiftUI, UIKit, WebKit and AVKit** — native interface, drop handling, embedded engine and playback.
- **[Bitrig’s Duo guide](https://bitrig.com/blog/iphone-duo-app-development)** — fold-aware layout and simulator development reference. Bitrig is not the music-generation API.
- **Reactor / Orbis** — live world-model video generation via `@reactor-team/js-sdk`.
- **Google Gemini and Lyria** — picture interpretation, lyrics, reactive speech, instrumental music, final song and edit planning.
- **RevenueCat** — optional browser checkout and server-side entitlement checks.
- **Blender** — local rendering of the AI-directed final edit.
- **FFmpeg / FFprobe** — media inspection, encoding and soundtrack preparation.
- **Next.js, React, TypeScript and Lucide** — local API server and browser studio.

The project thumbnail and illustrative scene assets use AI-generated imagery. Demo screenshots are actual app captures. Some demo pictures depict public figures; they do not imply their participation in or endorsement of DropBeat.
